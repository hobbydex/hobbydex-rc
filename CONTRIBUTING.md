# Contributing

Hobbydex is not crowdsourced. The project maintains the data and the tools
that build it; pull requests against `data/` are closed without review.

What helps: an issue that tells us about

- a brand or product line that is missing;
- a source we do not use yet: a manual, a parts list, an exploded view, a
  maker's catalogue page;
- an error: a wrong number, a wrong fit, a part filed under the wrong car.

Open one at https://github.com/hobbydex/hobbydex-rc/issues/new, or use the
"report an error" link at the bottom of any page on hobbydex.com. Every
report is read and the data is fixed from the maker's source.

Should the project open up contributions one day, they will be kept in
their own files beside the dataset, not written into its history.
